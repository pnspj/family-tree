# かけいず（family-tree）

子供に家族・親戚のつながりを教えるための、ブラウザだけで動く家系図エディタです。
データはブラウザ内（IndexedDB）にだけ保存され、外部には送信されません。

## 主な機能

- **みる**：カードを押すと、その人から見た続柄に切り替わる。名前・続柄を隠して当てっこもできる
- **クイズ**：「〇〇から見て『おばあさん』はどの人？」「〇〇は〇〇の何？」に答えて得点を競う
- **へんしゅう**：人物の登録・編集、親・配偶者・子・きょうだいの追加、つながりの修正
- 表示文字の切り替え（かんじ／ふりがな／ひらがな）、家庭ごとの呼び方（パパ・ばあば など）
- 印刷（A4/A3、名前や続柄を空欄にした書きこみプリント）、SVG/PNG での保存
- JSON での書き出し・読み込み（自分の端末の間の移動と控えのためだけ。どちらも注意事項を読んで同意してから操作）
- 「このアプリについて」のページ：コンセプトと機能の紹介。見本の家族で続柄の切り替え・ひらがな表示・隠すクイズを試せる（保存しない）。初回はこのページの最下部で同意し、同意後はメニューから `#about` で開ける。編集画面の画像は [tools/capture_form.mjs](tools/capture_form.mjs) で見本の家族から撮り直せる
- 初回（と規約の改定時）に、保護者（成人）が利用規約・免責事項とプライバシーポリシーに同意してから使う（同意前はストレージに一切触れない。改定時は同意カードだけを表示）
- [しくみと注意のページ](app/public/guide.html)：アプリの仕組み、個人情報の守り方、ファイルの約束を、図とふりがな付きで説明（子供の学習教材にもなる。[tools/build_guide.py](tools/build_guide.py) で生成）

## 開発

```bash
cd app
npm install
npm run dev     # 開発サーバー
npm test        # テスト
npm run build   # app/dist に出力
```

## 公開

- GitHub Pages：`.github/workflows/deploy.yml` が main への push でビルド・公開します（リポジトリ設定の Pages > Source を「GitHub Actions」にする）。
- Cloudflare Pages：ビルドコマンド `npm run build`、ルートディレクトリ `app`、出力先 `dist`。
